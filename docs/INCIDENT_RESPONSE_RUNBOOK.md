# Temporal Risk Incident Response Runbook & Triage Matrix

**Document Version:** 1.0.0  
**Scope:** Security Incident Response, Privilege Path Containment, and Escalation Procedures  
**Target Audience:** Tier-2 / Tier-3 Security Operations Center (SOC) Engineers, Incident Responders  

---

## 1. Incident Severity & Triage Matrix

When ARF-RT dispatches an alert or generates a high-risk profile during continuous audit:

| Severity | Risk Score Range | Trigger Conditions | SLA to Containment | Initial Action |
|---|---|---|---|---|
| **P1 - CRITICAL** | $[0.80, 1.00]$ | Expired active credential or multi-hop path reaching admin with high feasibility | $< 15$ minutes | Automated session revocation via `TemporalRemediationPlanner` |
| **P2 - HIGH** | $[0.60, 0.80)$ | Impossible travel velocity violation or stale key used in privileged escalation | $< 1$ hour | Temporary permission boundary attachment & principal quarantine |
| **P3 - MEDIUM** | $[0.40, 0.60)$ | Unapproved session duration extension or unmonitored concurrent role assumption | $< 24$ hours | Notify asset owner and initiate scheduled credential rotation |
| **P4 - LOW** | $[0.00, 0.40)$ | Inactive credential approaching 60-day warning threshold | Next sprint | Automated ticket creation in Jira / ServiceNow |

## 2. Emergency Containment Playbook (P1 Incidents)

### Step 1: Immediate Session Revocation
Execute the AWS CLI command template generated by `scripts/generate_remediation_plan.py`:

```bash
# Revoke all sessions issued prior to current UTC timestamp
aws iam put-role-policy \
  --role-name <COMPROMISED_ROLE_NAME> \
  --policy-name EmergencyRevokeSessions \
  --policy-document '{"Version":"2012-10-17","Statement":[{"Effect":"Deny","Action":"*","Resource":"*"}]}'
```

### Step 2: Invalidate Ephemeral STS Tokens
Attach the AWS managed `AWSDenyAll` permission boundary to prevent active tokens from invoking AWS APIs:

```bash
aws iam put-role-permissions-boundary \
  --role-name <COMPROMISED_ROLE_NAME> \
  --permissions-boundary arn:aws:iam::aws:policy/AWSDenyAll
```

### Step 3: Forensic Preservation
Dump the chronological credential timeline using ARF-RT:

```bash
python scripts/score_credentials.py --input /var/log/cloudtrail/latest.json --format json --out forensic_evidence.json
```
