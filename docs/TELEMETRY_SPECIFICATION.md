# ARF-RT Audit Logging & Telemetry Specification

## 1. Event Model
All audit log events generated by ARF-RT engine evaluations use structured JSON records.

### Hop Audit Event Schema
```json
{
  "timestamp": "2026-10-17T12:00:00Z",
  "event_type": "HOP_AUDIT",
  "edge_id": "edge_e1",
  "source_principal": "arn:aws:iam::111:user/attacker",
  "target_principal": "arn:aws:iam::222:role/admin",
  "verdict": "FEASIBLE",
  "witness": null,
  "elapsed_ms": 0.42
}
```

### Invariants
- Timestamps are strictly in UTC ISO-8601 format ending with `Z`.
- When `verdict` is `INFEASIBLE`, `witness` contains the specific constraint violation identifier.
- Zero-pruning invariant guarantees audit logging produces no side-effects on path ranking.
