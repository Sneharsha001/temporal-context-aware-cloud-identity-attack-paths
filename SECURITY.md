# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The ARF-RT team takes the security of this research platform seriously.
If you discover a vulnerability or security flaw, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to the repository owner: `sneharshathammisetty@gmail.com`.
3. Include details of the potential vulnerability, steps to reproduce, and any relevant logs or proof of concept.

We appreciate your efforts to responsibly disclose findings and will coordinate a timely remediation.
